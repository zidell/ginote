# Ginote

Ginote는 GitHub Issues를 개인 노트로 사용할 수 있게 해 주는 웹 앱입니다.

서비스 주소(누구나 바로 사용 가능): [https://note.gitools.net](https://note.gitools.net)

## 문서

### 사용자·데이터

- [첨부파일 저장 방식](docs/ATTACHMENTS.md): 저장 위치, 권한, 제한, 보관과 정리
- [노트 잠금과 암호화 방식](docs/ENCRYPTION.md): 보호 범위, 저장 형식, 배포 설정

### 데스크톱 앱·배포

- [데스크톱 앱 문서](docs/DESKTOP.md): 설치, 로컬 실행, 패키징, 릴리스
- [코드 서명 정책](docs/CODE_SIGNING.md): Windows 서명과 개인정보 처리 범위

### 프로젝트 유지보수

- [미리보기 GIF 만들기](docs/screencasting.md): README 미리보기 생성 절차
