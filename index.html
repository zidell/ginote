Ginote — private notes in your GitHub repository

Ginote is a free, serverless web app that uses the Issues of a private GitHub repository as personal notes. There is no Ginote account and no Ginote server: the app is static JavaScript, and your browser talks to the GitHub API directly, so notes and your access token never reach the site's operator. Running the app requires JavaScript.

How to start using it

  1. Sign in to GitHub, or create a free account at github.com/signup.
  2. Create a repository for your notes at github.com/new — for example issue-notes — and set Visibility to Private.
  3. Create a fine-grained personal access token at github.com/settings/personal-access-tokens/new: set Repository access to Only select repositories and pick that repository, then grant Issues: Read and write (required) and Contents: Read and write (required for attachments). Copy the token — GitHub shows it only once.
  4. Open this page with JavaScript enabled, enter the repository as owner/repository together with the token, and press Connect.
